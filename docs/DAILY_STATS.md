# Kunlik statistika

`Bugungi hissam` endi `user_daily_contributions` jadvalidan olinadi (`DISPLAY_TIMEZONE`, standart `Asia/Tashkent`).

- Har bir muvaffaqiyatli sync batch qaysi kalend kunida qabul qilingan bo‘lsa, shu kunga yoziladi.
- Migratsiyadan oldingi tarix avtomatik qayta taqsimlanmaydi: eski sessiyalar jami hisobda qoladi, lekin kunlik jadval bo‘sh bo‘lishi mumkin.
- Yarim tun atrofida faol vaqtni sekundma-sekund kunlarga bo‘lish keyingi yaxshilash (client/server segmentlari) bilan qo‘shiladi.
